# The event and the speaker

A 30-minute conference slot, mid-afternoon on day two, in a 300-seat room. Ten
minutes of questions after, which the organisers say usually run to four.

The audience: working backend and platform engineers. Most have shipped
something with an LLM in it in the last year. Perhaps a fifth have run one in
production for more than six months. They are tired of demos.

The speaker: I ran the migration of our batch pipeline onto an agent-driven
system over fourteen months. It half worked, then broke expensively, then
worked. I have real numbers: cost per run before and after, the two outages it
caused, the three things we had to build ourselves.

Constraints I know about:

- The room has no working demo network. Anything live is a risk.
- The talk before mine is on the same topic area and is by a vendor.
- I am not a good improviser. If I go off script I lose four minutes.
- I have one genuinely funny slide and I want to keep it.
