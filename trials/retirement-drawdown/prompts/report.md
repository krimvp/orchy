Write the report to `DRAWDOWN.md` in the working directory.

You may create a file. You may not change `SITUATION.md` or `ASSUMPTIONS.md`,
which are the inputs, and the run checks that you did not.

The report holds, in this order:

1. The answer in three sentences: does the money last, and under what.
2. The four paths as a table, with the numbers the module gave. Copy them.
3. What sequence risk means here.
4. The guardrails, as rules the household can agree to now.
5. The rescue moves, with the signal that triggers each one.
6. One line saying this is arithmetic on stated assumptions, not advice.

`sections` is how many of those the file holds.
