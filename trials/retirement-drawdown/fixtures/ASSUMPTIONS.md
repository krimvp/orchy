# The assumptions this run uses

The simulation walks the pot through four fixed return paths, year by year. It
is not a Monte Carlo and does not pretend to be. The paths are:

- **Steady 5%** — the same nominal return every year. The comfortable case.
- **Lost decade first** — a long flat stretch with several down years at the
  start, followed by a strong recovery.
- **Crash in year three** — good years, then a 34% fall, then a normal
  recovery. This is the sequence-risk case.
- **High inflation, thin returns** — nominal returns of 1 to 3% while spending
  grows with inflation.

Spending grows with the inflation rate the run is given. Withdrawals come out
at the start of each year, before the return is applied, which is the harsher
of the two conventions.

Nothing here models tax, fees, pension income, or the house. The report should
say so.
