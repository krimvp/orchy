Write the plan to `PLAN.md` in the working directory. Change no other file.

The file holds, in this order:

1. What the money is for, in three lines.
2. A table of the sleeves: name, target share, what fills it, when to review.
3. The projection, with the blended return and the ending balance as the
   module computed them. Do not recompute these numbers. Copy them.
4. The risks, gathered from the sleeves, with the repeats removed.
5. One paragraph on what would make this plan wrong.

`sleeves_written` is how many sleeves the table holds.

This is a plan on a page, not advice from a licensed adviser. Say so in one
line at the end.
