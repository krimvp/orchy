Read `ISSUE.md` in the working directory.

Sort it:

- `kind` is `bug`, `feature`, `question`, or `noise`.
- `severity` is `low`, `medium`, or `high`. Judge it by what a user loses, not
  by how the report sounds.
- `missing` holds the facts a person must add before anyone can act. Leave it
  empty when the report is complete.

Write the summary in two sentences. Do not repeat the report.
